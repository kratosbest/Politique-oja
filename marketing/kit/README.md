# Kit marketing OJA — comment l'utiliser avec Claude

## Option A — Claude Code (recommandé)
1. Dézippe ce dossier, ouvre un terminal dedans.
2. Lance `claude`. Claude lit automatiquement `CLAUDE.md`.
3. Copie-colle un prompt du dossier `prompts/` (ex. `prompts/01-scripts-videos.md`).
4. Demande à Claude d'enregistrer les résultats dans un dossier `sorties/`.

## Option B — claude.ai (Projet)
1. Crée un Projet « OJA Marketing ».
2. Dans « Instructions du projet », colle le contenu de `CLAUDE.md`.
3. Ajoute tous les autres fichiers `.md` aux connaissances du projet.
4. Lance une conversation avec un prompt de `prompts/`.
