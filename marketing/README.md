# Marketing OJA — kit et contenus produits

- `kit/` : le kit marketing fourni (règles, fonctions réelles, idées, prompts, modèles). Ne pas modifier : c'est la référence.
- `sorties/` : les contenus produits en déroulant les prompts du kit, de 00 à 09.

| Prompt | Fichier(s) dans `sorties/` | Contenu |
|---|---|---|
| 00 | `00-synthese.md` | Ce qu'il faut retenir d'OJA, fonctions à ne pas promouvoir avant la version store, autres dépendances |
| 01 | `scripts/` | 5 scripts vidéo (idées 1, 5, 9, 15, 22) : 2 accroches, versions 30 s et 15 s, adaptation 9:16 et 4:5 |
| 02 | `legendes/` | Légendes Facebook, TikTok, Instagram et statut WhatsApp pour chaque script |
| 03 | `carrousels/` | 5 carrousels de 8 diapositives (titre ≤ 6 mots, texte ≤ 20 mots, visuel) |
| 04 | `calendrier.md`, `calendrier.csv` | Calendrier jour par jour de J-14 à J+30 (66 publications), avec les vidéos déjà produites dans `motion/` |
| 05 | `micro-trottoir.md` | 3 micro-trottoirs (Dantokpa, campus UAC, Haie Vive) |
| 06 | `recrutement-chauffeurs.md` | 3 vidéos, 1 affiche de parking, 1 message vocal WhatsApp (français + version à faire traduire en fon) |
| 07 | `commercants.md` | 3 vidéos témoignage, flyer A5, argumentaire terrain d'une minute, 5 objections |
| 08 | `affiches-et-radio.md` | 5 affiches, 3 spots radio de 30 s (français + versions à faire traduire en fon) |
| 09 | `verification.md` | Contrôle de chaque contenu, corrections faites, points à trancher par l'équipe |

Tout ce qui est `[ENTRE CROCHETS]` est à remplir avec une valeur réelle avant tournage ou publication. Chaque contenu indique sa **dépendance** (version store, Défis activés, décaissement MTN…).
